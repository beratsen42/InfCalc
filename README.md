# İnfüzyon Hızı Hesaplayıcı

İlaç infüzyon hızı hesaplayan basit bir web uygulaması. Tek dosya: `index.html`. Sunucu gerekmez, internetten hiçbir şey yüklemez.

**Canlı:** https://beratsen42.github.io/infcalc/

## Özellikler

- **Doz → mL/hr:** İlaç miktarı (mg), hacim (mL), doz ve gerekirse kilo girilir. Pompa hızı mL/hr olarak çıkar.
- **mL/hr → Doz:** Pompa hızı girilir. Hastanın aldığı doz seçilen birimde çıkar.
- İki doz ya da iki hız aynı anda hesaplanabilir.
- Birimler: mcg/kg/min, mg/kg/min, mcg/min, mg/min, mcg/hr, mg/hr.
- Hesaplama adımları açılıp görülebilir.
- Ondalık için virgül ya da nokta kullanılabilir.
- Açık ve koyu tema, telefonun ayarına göre.

## GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, klasör: `/ (root)` → Save.
